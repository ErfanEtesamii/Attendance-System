# استقرار فاز ۱۵

## R1 — سؤال هنگام خروج (⚠️ در تعارض با R1 جدیدِ میکرو‌پرامپت؛ نگاه کنید به PHASE15_DECISIONS ← G1)
- بعد از استقرار، تنظیم «dailyReportGateMode» را در پنل ادمین بررسی کنید؛ اگر قبلاً `off` ذخیره شده، پیش‌فرض جدید اثر نمی‌کند و باید دستی `soft` یا `enforce` شود.
- پیشنهاد: چند روز اول `soft` (خروج مجاز + «بعداً پر می‌کنم»)، بعد `enforce`.
- `enforce` یعنی کارمند بدون تعیین‌وضعیت تسک‌های الزامی (اولویت بالا/عادی) نمی‌تواند خروج بزند.

## H — گزارش شبانه‌ی تسک‌ها
- زمان‌بندی `cronNightlyReview` (پیش‌فرض ۲۰:۰۰) را **بعد از پایان آخرین شیفت** بگذارید (مثلاً `30 21 * * *` = ۲۱:۳۰)؛ وگرنه اعضای هنوز-در-محل «⏳ هنوز خروج نزده — وضعیت لحظه‌ای» می‌گیرند و وضعیت نهایی‌شان فقط در خلاصه‌ی صبحگاهی می‌آید. این مقدار عمداً تغییر داده نشد.
- ساعت خلاصه‌ی صبحگاهی («دیرهنگام‌ها») از همین cron خوانده می‌شود؛ پس از تغییر cron نیازی به کار دیگری نیست.
- تنظیم جدید «حداکثر پیام گزارش تسک‌ها برای ادمین» (`taskReportAdminMaxParts`، پیش‌فرض ۶): ادمین از این نسخه گزارش **همه‌ی تیم‌ها** را می‌گیرد؛ در شرکت بزرگ مقدار را بالا ببرید یا به «🖥 گزارش کامل در پنل» تکیه کنید.
- مهاجرت دیتابیس ندارد.

## G1 — مراحل استقرار
1. `npm test && npm run smoke && npm run secret-scan` (روی سیستم خودتان؛ تست‌های سرور در محیط توسعه اجرا نشده‌اند).
2. `.\deploy\nssm.exe stop FarazHonarAttendance` ← جایگزینی کد ← `npm install` ← `npm run migrate` (⇒ ۰۳۹) ← `.\deploy\nssm.exe start FarazHonarAttendance`.
3. تنظیم‌های پس از استقرار: `cronNightlyReview` بعد از آخرین شیفت (مثلاً ۲۱:۳۰)؛ `taskReportAdminMaxParts` (پیش‌فرض ۶)؛ `selfUrgentEnabled` (پیش‌فرض روشن؛ هر کاربر از «وضعیت من» یا Mini App می‌تواند برای خودش تسک فوری بسازد)؛ `taskCarryMaxTimes` (اختیاری، مثلاً ۳). `dailyReportGateMode` را تا اجرای R1 جدید بررسی کنید (نگاه کنید به بخش R1 بالا).

## چک‌لیست تست دستی (بندهای قابل‌انجام با کد فعلی)
۱) «امروز من»: تیک ⇒ انجام‌شده + توضیح؛ ذخیره‌ی توضیح؛ برداشتن تیک. ۲) برنامه‌ی هفتگی با کادرهای رنگی؛ کلیک روی تسک ⇒ جزئیات (موبایل/عریض، دو تم). ۳) انتقال به فردا و تاریخ مشخص با علت؛ ظاهرشدن در روز مقصد؛ واگرد. ۴) روز بعد: چیپ «روزهای قبل (N)». ۵) تسک اضافه‌شده‌ی مدیر: قابل تیک/انتقال، نه حذف. ۶) سرپرست در پنل: «توضیح انجام» و «⚡ فوری (خودش)» فقط‌خواندنی؛ hr هم. ۷) `saveDraft` تیک/توضیح/انتقال را پاک نکند. ۸) ۳۲۰px، کیبورد و صفحه‌خوان در «امروز من». ۹) سرپرست: گزارش شبانه فقط تیم خودش با «✗ با علت / ⏳ بدون وضعیت». ۱۰) ادمین: همه‌ی افراد با گروه‌بندی تیم + خلاصه‌ی شرکت در پیام آخر؛ با ۱۰۰ نفر هر پیام ≤ ۴۰۹۶. ۱۱) «هنوز خروج نزده» و «وضعیت نهایی دیروز» صبح بعد؛ چند ادمین هرکدام گزارش کامل. — بندهای «خروج بدون سؤال»، «⚡ فوریِ خودش از Mini App» و «همه به فردا» منتظر R1/D3/E1 هستند.
