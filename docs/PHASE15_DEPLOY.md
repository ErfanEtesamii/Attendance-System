# استقرار فاز ۱۵

## R1 — سؤال هنگام خروج
- بعد از استقرار، تنظیم «dailyReportGateMode» را در پنل ادمین بررسی کنید؛ اگر قبلاً `off` ذخیره شده، پیش‌فرض جدید اثر نمی‌کند و باید دستی `soft` یا `enforce` شود.
- پیشنهاد: چند روز اول `soft` (خروج مجاز + «بعداً پر می‌کنم»)، بعد `enforce`.
- `enforce` یعنی کارمند بدون تعیین‌وضعیت تسک‌های الزامی (اولویت بالا/عادی) نمی‌تواند خروج بزند.
