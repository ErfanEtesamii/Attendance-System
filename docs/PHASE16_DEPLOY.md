# استقرار فاز ۱۶ (بازطراحی ظاهر پنل مدیریتی)

فقط فایل‌های ایستا و تست تغییر کرده‌اند: **بدون migration، بدون تنظیم/متغیر محیطی جدید، بدون تغییر API و بک‌اند.**

## فایل‌های اثرگذار

- پنل: `public-admin/css/style.css`، `public-admin/js/views-main.js`، `public-admin/js/views-admin.js` (فقط نمودارها)، `public-admin/index.html` (ترتیب لینک `datepicker.css` — T6)
- مشترک با Mini App: `public/js/theme.js` (فقط `BG.dark`)، `public/js/states.js` (اسکلت `settings`)
- Mini App: `public/css/style.css`، `public/css/planner.css`، `public/index.html` (فقط `theme-color`)، `public/js/app.js` (فقط سه ثابت فالبک رنگ)
- تست و مستند: `test/*`، `docs/PHASE16_DECISIONS.md`

## مراحل

1. `npm test && npm run smoke && npm run secret-scan` روی سیستم خودتان (در محیط توسعه فقط تست‌های ایستا/DOM ساختگی اجرا شده‌اند و `smoke` به‌خاطر sqlite بومی نیاز به اجرا روی سیستم شما دارد).
2. جایگزینی فایل‌ها و (اختیاری، بی‌خطر) restart سرویس با `.\deploy\restart_service.bat`؛ برای فایل‌های ایستا لازم نیست.
3. فایل‌های ایستا نسخه‌ی URL ندارند و با ETag دوباره‌اعتبارسنجی می‌شوند؛ اگر مرورگر نسخه‌ی قدیمی نشان داد یک‌بار Ctrl+F5. Mini App: دکمه‌ی «بستن» و بازکردن دوباره‌ی برنامه در تلگرام (وب‌ویوی تلگرام ممکن است CSS را نگه دارد).
4. **بازگشت (rollback):** برگرداندن همین فایل‌ها (یا `git revert` کامیت‌های فاز ۱۶)؛ داده‌ای تغییر نکرده است.

## چیزهایی که باید بعد از استقرار با چشم دید (کد تست نمی‌کند)

- پنل در **تم روشن و تیره**: حالت «خودکار» از سیستم/تلگرام پیروی می‌کند و فقط وقتی سیستم نامعلوم باشد روشن (`default-theme=light`) می‌شود.
- ریل آیکنی: حالت ریل/بازشده، قرص فعال و نوچ‌ها، تولتیپ، کشوی موبایل. اگر نوچ در مرورگری ناصاف بود حذف دو قاعده‌ی `.nav-item.active::before/::after` قرص ساده می‌دهد.
- نمودار داشبورد: میله‌ی «تأخیر» راه‌راه و افسانه؛ تحلیل‌ها (۶ سری).
- Mini App داخل تلگرام: رنگ هدر/نوار پایین، «امروزِ من»، برنامه‌ی هفتگی.
- ۳۲۰px/۷۶۸px/۱۴۴۰px بدون اسکرول افقی؛ چاپ جدول/هفته/تقویم؛ High Contrast ویندوز؛ کاهش حرکت.
